# Cleo icon proposals

These are vector proposals based on the existing application's mint-to-violet orb gradient. They are not installed app icons. The user requested confirmation before replacing the Electron icon.

- A — `a-pure-orb.svg`: transparent orb, closest to the existing identity.
- B — `b-pearl-tile.svg`: orb on a soft macOS tile; recommended.
- C — `c-midnight-orbit.svg`: dark tile with an orbit ring.

After selection, render the chosen vector into the macOS iconset sizes, build an `.icns`, wire it into local packaging and Dock rendering, and inspect it at small sizes. Retain the other proposals as design references.

The user requested asymmetric placement with most of the orb visible:

- D — `d-bottom-left.svg`: light tile, orb cropped at bottom and left.
- E — `e-bottom-right.svg`: dark tile, orb cropped at bottom and right.
- F — `f-left-edge.svg`: light tile, orb cropped mostly at the left edge.

These remain proposals awaiting selection.
